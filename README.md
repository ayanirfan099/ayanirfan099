# Hi, I'm Ayan

I build reproducible machine-learning systems with an emphasis on honest evaluation, source-grounded outputs and production-minded engineering.

## Selected projects

- **[Paper Evidence Retrieval](https://github.com/ayanirfan099/paper-evidence-retrieval)** — page-aware PDF retrieval using BM25, FAISS and reciprocal-rank fusion, with citations and abstention.
- **[Machine Learning from First Principles](https://github.com/ayanirfan099/ml-from-first-principles)** — NumPy implementations of regression, KNN, K-means and PCA, validated against scikit-learn.
- **[Telecom Churn Prediction](https://github.com/ayanirfan099/telco-churn-prediction)** — leakage-resistant classification, threshold selection and explainability.
- **[CNN and Transfer-Learning Study](https://github.com/ayanirfan099/cnn-transfer-learning-study)** — controlled CIFAR-10 experiments with ResNet18 and Grad-CAM.
- **[Neural Network Generalization](https://github.com/ayanirfan099/neural-network-generalization)** — controlled ablations covering dropout, weight decay and data augmentation.
- **[Vienna Cuts Booking Platform](https://github.com/ayanirfan099/vienna-cuts-booking-platform)** — bilingual full-stack appointment booking with conflict-safe scheduling and owner workflows.
